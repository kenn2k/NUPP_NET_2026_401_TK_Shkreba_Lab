## Опис предметної області

Інтернет-магазин — це система для представлення товарів та їх продажу покупцям через веб або мобільний інтерфейс. Каталог об’єднує товари за категоріями та зберігає їхні назви й ціни. Покупець може переглядати доступні позиції, додавати їх до кошика та оформлювати замовлення. У цьому навчальному проєкті доменна модель винесена до окремої бібліотеки `OnlineStore.Domain`.
