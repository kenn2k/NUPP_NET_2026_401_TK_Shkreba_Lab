# Відповіді на контрольні питання

1. **Git** — система контролю версій, що зберігає історію змін файлів
2. **GitHub і GitLab** — це сервіси для віддаленого розміщення Git-репозиторіїв та спільної роботи; Git це інструмент для контролю версій
3. **Repository** — сховище файлів проєкту
4. **Commit** — зафіксований стан змін у репозиторії
5. **Branch** — окрема гілка розробки
6. **HEAD** — вказує на поточний коміт або активну гілку
7. **Merge** — об’єднує історію та зміни однієї гілки з іншою
8. **Pull Request** — пропозиція внести зміни в репозиторій
9. **.NET project** — окремий застосунок або бібліотека; **solution** об’єднує один чи кілька проєктів для спільної розробки
10. **.csproj** — інструкція для збирання проєкту
11. **Project reference** — для повʼязання декількох проєктів
12. Код винесено до окремого Domain-проєкту, щоб відокремити бізнес-модель від інтерфейсу
